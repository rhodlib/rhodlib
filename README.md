### About

**Software Engineer & Data Scientist** based in Mar del Plata, Argentina 🇦🇷

Full-stack engineer with a strong product and data focus. I work comfortably across the whole stack — a Python tool editor, a TypeScript AI-agent module, or a Terraform configuration — and I enjoy problems that sit at the boundaries, where backend, frontend, data, and models all have to speak the same language.
